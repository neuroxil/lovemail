# 💗 Date Invitation

An interactive romantic date invitation website.

It starts with:

> "I really like you. soooo uh... wanna go on a date with me?"

The visitor can choose YES and then enter:

- 📍 Place
- 🗓 Date
- 🕐 Time

Once confirmed, the backend sends the date information to a Telegram chat.

---

## ✨ Features

- Romantic animated UI
- Animated hearts
- Butterflies
- Flowers
- Sparkles
- Floating particles
- Background orbs
- Mouse parallax
- Responsive mobile layout
- Evasive NO button
- Date/place/time selection
- Telegram notification
- Server-side bot token
- Basic input validation
- Express backend
- GitHub-ready structure
